# Physical-Computing-Project-2026---IT-KMITL

# บทคัดย่อ
ในยุคปัจจุบันที่สภาพอากาศแปรปรวนและไม่สามารถคาดเดาได้ ทำให้การทำกิจวัตรประจำวันวันนั้นลำบากไปด้วย ซึ่งการเก็บเสื้อผ้าไม่ทันเพราะฝนตกผิดฤดูนั้น ก็เกิดจากสภาพอากาศแปรปรวนเช่นกัน

ผู้พัฒนาจึงได้คิดค้นหลังคาอัจฉริยะ (smart roof) ขึ้นมาเพื่อลดปัญหาในการเก็บเสื้อผ้าไม่ทัน โดยออกแบบให้หลังคาสามารถเปิดและปิดอัตโนมัติได้ ซึ่งตรวจจับจากน้ำฝนที่ตกลงมาบนอุปกรณ์ที่ชื่อว่า rain sensor และยังมีระบบเปิดและปิดหลังคาที่ผู้ใช้สามารถควบคุมเองได้ ในกรณีที่ผู้ใช้นั้นนำหลังคาอัจฉริยะ (smart roof) ไปประกอบกับอุตหาหกรรมอย่างอื่น เช่น แปลงผัก เป็นต้น

# คุณสมบัติ
- เปิดปิดหลังคาแบบอัตโนมัติและแบบควบคุมเองได้
- หบังคาเปิดอัตโนมัติเมื่อฝนตก
- มีการเชื่อมต่อ WiFi เพื่อควบคุมระยะไกล
- มี website สำหรับควบคุมการเปิดปิดหลังคาเองได้

# อุปกรณ์ hardware ที่ใช้
- Breadboard
- Arduino UNO R4 WIFI
- Servo motor SG90
- Rain sensor
- สายจัมป์ไฟ (ผู้-เมีย)

# การทำงาน
- ระบบอัตโนมัติ
เมื่อมีฝนตกลงบน Rain sensor ตัว Arduino จะสั่งให้หลังคาเปิด เมื่อน้ำบน Rain sensor แห้งแล้ว Arduino จะสั่งปิดหลังคาโดยอัตโนมัติ

- ระบบควบคุมระยะไกล (บังคับการเปิดปิดเอง)
เมื่อกดเปิดหรือปิดหลังคาบน website แล้ว Arduino จะสั่งเปิดหรือปิดหลังคาตามที่ผู้ใช้ต้องการ

กรณีฝนตกอยู่ ซึ่งปกติแล้วหลังคาจะกางออกอัตโนมัติ แต่อยู่ดีๆผู้ใช้กดปิดหลังคาผ่าน website หลังคาก็จะปิด และจะไม่เปิดจนกว่าฝนจะตกครั้งถัดไป หรือไม่ก็ผู้ใช้กดเปิดเอง

กรณีฝนไม่ได้ตกอยู่ ซึ่งปกติแล้วหลังคาจะปิดอยู่ แต่อยู่ๆผู้ใช้กดเปิดหลังคาผ่าน website หลังคาก็จะเปิด และจะไม่ปิดจนกว่าผู้ใช้จะกดปิดเอง
